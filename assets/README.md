# Brand assets

The Verdant name, the mark and the artwork in this directory are **not** covered
by the [MIT licence](../LICENSE) that applies to the rest of the repository.

The code is yours to take. Under MIT you may run the factory, the hook and the
schedule library as your own launchpad, and that is deliberate — see the licence
note in the [README](../README.md#licence). What you may not do is present it as
Verdant, because the point of the exclusion is that someone landing on a
deployment can tell whose it is.

| File | Used for |
| --- | --- |
| `verdant-cover.jpg` | The header of the root README |
| `verdant-mark.png` | The mark on its own |

Both are copies of the canonical assets in
[`apps/web/public/brand/`](../apps/web/public/brand/), kept here so the README
does not depend on a path inside an application that may move. The pipeline that
generates them is documented in
[`apps/landing/public/brand/README.md`](../apps/landing/public/brand/README.md).
